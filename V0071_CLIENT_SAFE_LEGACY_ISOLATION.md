# v0.07.1 — Client-Safe Legacy Isolation

Legacy is no longer part of the normal client interface.

Primary client engine: **MK Institutional Tactical**.

Legacy remains only for Golden Master reproducibility, forensic comparison, and internal model audit. It is hidden by default behind `Governance & Internal Audit -> Show Legacy Audit Layer`.

If Tactical is disabled, the app shows **NO PRIMARY DECISION** and never falls back to Legacy.

Normal client views now use Tactical/NW for executive decisions, price signals, strategy comparison, risk, diagnostics, trade actions, and calculation ledgers.
